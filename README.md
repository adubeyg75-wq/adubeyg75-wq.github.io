# CS Arora website

Static marketing website for CS ARORA, Prayagraj. All editable site copy, SEO copy and structured-data values live in `src/content/site.ts`.

The project builds to a static `out/` folder using Next.js App Router. Forms are client-side and require a configured endpoint before launch.

See `HANDOFF.md` for setup, environment variables, content editing, course publishing, form endpoints, hosting options and the launch checklist.

## Quick start

```bash
npm install
npm run dev
npm run build
```

The generated static site is in `out/`.
